# Pilot plan and current limits

Actual correct curl RESOLVE with each hop manually policy-checked will be compared
to this SDK on identical origins, address schedule, bodies and redirect policy.
No global novelty or performance advantage is assumed. A URL-only check followed
by a changing ordinary resolver is a separate weakened control, explicitly labeled.
Listener counters, full body bytes/hash, actual setup/DNS/connect/call/time costs
and normal/mixed-DNS/redirect/TLS refusals will be retained. Correct mature control
can have equivalent refusal results, and ordinary small responses can be cheaper.
Customer/revenue/production-demand and SSRF safety certification remain unknown.
Current initial tests are real laboratory listeners and a complete1000order sink
consumer, not a finalized fair performance pilot or independent score.
